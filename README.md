# Run and deploy EduReach

This repository contains the EduReach frontend and backend.

## Run Locally

**Prerequisites:** Node.js


1. Install dependencies:
   `npm install`
2. Set `VITE_API_BASE_URL` in `.env.local` (example: `http://localhost:8000/api`)
3. Run the app:
   `npm run dev`
